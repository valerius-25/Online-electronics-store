# Online Store (React SPA)

## Description
Single-page application built with React and Vite that simulates
an online electronics store.

The project is created as a portfolio demo.

## Products
- Arduino boards
- Arduino displays
- Power supplies and batteries
- Sensors
- Modules
- Connectivity components

Including:
- Charging modules
- Boost converter modules
- Buck (step-down) converter modules
- Digital temperature and humidity sensor modules
- PIR motion sensors for DIY projects
- Mini LED matrices
- WiFi transceiver modules
- Bluetooth modules
- Wireless transceivers

## Features
- Product catalog (80+ items)
- Shopping cart with total price calculation
- Quantity management per product
- Cart persistence using localStorage
- Multilingual support (RU / EN / HY) via i18next
- Dark / Light theme (React Context)
- Product pages with descriptions, parameters and image galleries
- Client-side routing

## Technologies
- React
- Vite
- React Router
- Axios / Fetch
- i18next
- JSON Server
- Tailwind CSS

## Styling
All UI styling is implemented using Tailwind CSS utility classes.
